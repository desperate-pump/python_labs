## Задание A. Чтение TXT и запись CSV

**Файл:** [`io_txt_csv.py`](io_txt_csv.py)

Реализован модуль с функциями для чтения текстовых файлов и записи таблиц в CSV.

| Функция | Назначение |
| :--- | :--- |
| `read_text(path, encoding="utf-8")` | Читает весь текст из файла и возвращает строку. |
| `write_csv(rows, path, header=None)` | Создаёт или перезаписывает CSV с разделителем `,`; при необходимости добавляет заголовок. |
| `ensure_parent_dir(path)` | Создаёт отсутствующие родительские папки перед записью. |

**Примеры запуска из корня репозитория:**

```bash
python3.12 -c 'from src.lab04.io_txt_csv import read_text; print(read_text("data/input.txt"))'
python3.12 -c 'from src.lab04.io_txt_csv import write_csv; write_csv([("кот", 2)], "data/lab04/check.csv", header=("word", "count"))'
```

**Кодировки и особые случаи:**

- По умолчанию используется **UTF-8**. Файл в Windows-1251 можно прочитать с параметром `encoding="cp1251"`.
- Пустой TXT возвращает пустую строку `""`; отсутствующий файл вызывает `FileNotFoundError`, неподходящая кодировка — `UnicodeDecodeError`.
- Перед записью CSV проверяется одинаковое число столбцов в строках. При несоответствии возникает `ValueError`.
- Пустой `rows` без заголовка создаёт пустой CSV; с `header` в файле остаётся только заголовок.
- По условию работы текст читается целиком; в реальных проектах очень большие файлы удобнее обрабатывать построчно.

## Задание B. Статистика текста и CSV-отчёт

**Файл:** [`text_report.py`](text_report.py)

Программа читает входной TXT, обрабатывает его функциями `normalize()`, `tokenize()`, `count_freq()` и `top_n()` из [`src/lib/text.py`](../lib/text.py), считает слова и сохраняет частоты в CSV.

**Порядок обработки:** чтение TXT → нормализация → разбиение на слова → подсчёт частот → сортировка → запись CSV.

Сортировка выполняется по **количеству в порядке убывания**, а при одинаковом количестве — **по слову в алфавитном порядке**.

**Запуск из корня репозитория:**

```bash
python3.12 src/lab04/text_report.py
```

**Запуск с указанием входного и выходного файлов:**

```bash
python3.12 src/lab04/text_report.py --in data/input.txt --out data/report.csv
```

**Для входного файла в кодировке CP1251:**

```bash
python3.12 src/lab04/text_report.py --in data/input.txt --out data/report.csv --encoding cp1251
```

> Параметр `--encoding cp1251` применяется только к файлам, действительно сохранённым в Windows-1251. Пример `data/input.txt` в репозитории имеет кодировку UTF-8.

**Пример входного файла `data/input.txt`:**

```text
Привет, мир! Привет!!!
```

**Вывод программы в терминале:**

```text
Всего слов: 3
Уникальных слов: 2
Топ-5:
привет:2
мир:1
```

**Полученный файл `data/report.csv`:**

```csv
word,count
привет,2
мир,1
```

**Особые случаи:** если входной файл пустой, отчёт содержит только заголовок `word,count`, а количество слов равно нулю. Если файл не найден или не может быть прочитан, программа выводит понятное сообщение об ошибке и завершается с кодом `1`.
