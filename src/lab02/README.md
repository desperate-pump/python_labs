
# Лабораторная работа 2. Коллекции и матрицы

### Задание A. Операции со списками
* **Скрипт:** `arrays.py`
* **Описание:** реализованы функции `min_max()` для поиска минимального и максимального значений, `unique_sorted()` для сортировки уникальных чисел и `flatten()` для объединения вложенных списков и кортежей. Поиск минимума и максимума, а также сортировка выполнены без запрещённых встроенных функций. Предусмотрена обработка некорректных данных.

**Пример работы:**
```python
print(min_max([3, -1, 5, 5, 0]))       # (-1, 5)
print(unique_sorted([3, 1, 2, 1, 3])) # [1, 2, 3]
print(flatten([[1, 2], [3, 4]]))       # [1, 2, 3, 4]
```

**Запуск скрипта:**
```bash
python3 src/lab02/arrays.py
```

### Задание B. Операции с матрицами
* **Скрипт:** `matrix.py`
* **Описание:** реализованы функции `transpose()` для транспонирования матрицы, `row_sums()` для вычисления сумм строк и `col_sums()` для вычисления сумм столбцов. Предусмотрена проверка прямоугольности матрицы и обработка пустых матриц.

**Пример работы:**
```python
mat = [[1, 2, 3], [4, 5, 6]]

print(transpose(mat)) # [[1, 4], [2, 5], [3, 6]]
print(row_sums(mat))  # [6, 15]
print(col_sums(mat))  # [5, 7, 9]
```

**Запуск скрипта:**
```bash
python3 src/lab02/matrix.py
```

### Задание C. Форматирование записи студента
* **Скрипт:** `tuples.py`
* **Описание:** реализована функция `format_record()` для форматирования записи студента из кортежа. Функция формирует инициалы, удаляет лишние пробелы и выводит GPA с точностью до двух знаков после точки. Предусмотрена проверка корректности входных данных.

**Пример работы:**
```python
student = ("Иванов Иван Иванович", "BIVT-25", 4.6)
print(format_record(student))
# Иванов И.И., гр. BIVT-25, GPA 4.60
```

```bash
python3 src/lab02/tuples.py
```
